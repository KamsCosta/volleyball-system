# samples

Vídeos de teste e calibração do serviço de análise. Ficam só na máquina local:
o conteúdo desta pasta é ignorado pelo git (exceto este arquivo), porque são
arquivos pesados e contêm imagem de atletas.

Sugestão de nomes: `<habilidade>_<quem>_<n>.mp4`
(ex.: `toque_controlado_01.mp4`, `levantamento_professor_aluno_01.mp4`).
